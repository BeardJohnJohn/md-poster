# CSS 设计系统

本文档说明 XHS Card Generator 的 CSS 设计系统。你可以修改这些变量来自定义卡片的视觉风格。

## 核心色板

| 变量 | 值 | 用途 |
|------|------|------|
| 背景色 | `#F9F9F6` | 米白色卡片底色 |
| 标题色 | `#000000` | H1/H2 |
| 正文色 | `#1A1A1A` | 段落文字 |
| 辅助色 | `#4a9eff` | 链接、引用块边框 |
| 高亮色 | `#fff59d` | Mark 标记背景 |
| 边框色 | `#E8E6D9` | 分割线、头像边框 |

## 字体系统

从 Google Fonts 引入三种字体：

| 字体 | 用途 | 字重 |
|------|------|------|
| **Noto Serif SC** | 中文正文、标题 | 400 (正文), 700 (标题) |
| **Inter** | 英文、日期、页脚 | 300, 400, 700 |
| **JetBrains Mono** | 代码块 | 400, 700 |

## 字号体系

| 元素 | 字号 | 行高 |
|------|------|------|
| H1 主标题 | 56-60px | 1.3 |
| H2 章节标题 | 44px | 1.3 |
| 正文段落 | 34px | 2.0 |
| 表格 | 28px | 1.6 |
| 作者名 | 30px | 1.2 |
| 日期 | 22px | 1.3 |
| 页脚 | 20-22px | — |

## 间距规范

| 区域 | 间距 |
|------|------|
| 内容区内边距 | 90px (四边) |
| H1 下方间距 | 50px |
| H2 上下间距 | 68px / 34px |
| 段落间距 | 34px |
| 作者区域下方 | 50px |
| 页脚上方 | 50px |

## 卡片尺寸

| 参数 | 值 | 说明 |
|------|------|------|
| 宽度 | 1080px | 小红书原生分辨率 |
| 固定高度 | 1440px | 3:4 比例 |
| 自适应高度 | auto | 按内容高度 |

## 自定义示例

如果你想修改品牌配色，在 CSS 中搜索并替换：

```css
/* 将米白色改为纯白 */
background: #FFFFFF;  /* 原来是 #F9F9F6 */

/* 将引用块边框改为品牌色 */
border-left: 6px solid #YOUR_BRAND_COLOR;  /* 原来是 #4a9eff */
```

如果你想修改字体，替换 Google Fonts 链接中的字体名：

```html
<link href="https://fonts.googleapis.com/css2?family=YOUR_FONT:wght@400;700&display=swap" rel="stylesheet">
```

然后在 CSS 中更新 `font-family`。
