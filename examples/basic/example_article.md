# 为什么你需要一个自己的排版系统

每一个认真做内容的人，最终都会撞上同一面墙：**排版太累了。**

你花了三个小时写完一篇深度文章，结果还要再花两个小时把它变成小红书能发的图文卡片。打开 Canvas，调字号、拖文本框、对齐元素、导出 PNG……重复八次。

这不对。

## 代码比拖拽更快

想象一下另一种工作流：

1. 你用 Markdown 写完文章
2. 运行一个脚本，自动把文章切成 8 页卡片
3. 再运行一个命令，自动截图成 PNG
4. 全程不超过 30 秒

这就是 **HTML + CSS + Playwright** 的组合拳。

**核心原理很简单**：用 HTML 定义排版结构，用 CSS 控制视觉样式，用 Playwright（无头浏览器）把网页截图成图片。

听起来像是程序员才能干的事？不完全是。因为现在有 AI。

## AI 帮你写 HTML

你不需要自己写 HTML 代码。你只需要告诉 AI：

- 字体用思源宋体
- 背景是米白色 #F9F9F6
- 正文 34px，行高 2 倍
- 每页底部加一个页脚

AI 会帮你生成一个完整的 HTML 文件。你打开浏览器看一眼，觉得可以，就运行截图脚本。

**整个过程，你不需要写一行代码。**

## 为什么不用 Canvas / 美图秀秀

| 维度 | 手动工具 | HTML + 截图 |
|------|---------|------------|
| 一致性 | 每次手动调，容易走形 | CSS 锁死，永远一致 |
| 效率 | 8 页 ≈ 2 小时 | 8 页 ≈ 30 秒 |
| 可维护 | 改风格要重做所有图 | 改 CSS 一行，全部更新 |
| AI 友好 | AI 帮不了你拖拽 | AI 天生擅长写代码 |

这不是一个工具的选择，是一种**思维方式的切换**：从「手动操作」到「定义规则让机器执行」。

## 开始使用

这个仓库包含了你需要的所有文件：

- `xhs_card_template.html` — 卡片排版模板
- `screenshot.py` — 自动截图脚本
- `example/xhs_pages.py` — 完整的生成器示例

三步开始：

```bash
pip install playwright && playwright install chromium
python example/xhs_pages.py
python screenshot.py --auto-height
```

打开 `output/` 文件夹，你的小红书图文卡片就在那里。
